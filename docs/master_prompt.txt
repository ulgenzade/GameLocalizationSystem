================================================================================
GAMELOCALIZATIONSYSTEM — AI KODLAMA ASİSTANI MASTER PROMPTU
================================================================================

Aşağıdaki talimatları bir yapay zeka kodlama asistanına (Cursor, Claude, Copilot,
Windsurf vb.) vererek projenin C# iskeletini, XAML arayüzünü ve tüm kaynak
kodlarını sıfırdan üretebilirsiniz.

--------------------------------------------------------------------------------
MASTER PROMPT METNİ
--------------------------------------------------------------------------------

Herhangi bir oyunun .pak arşiv dosyalarından metin içeriklerini çıkaran, yapay
zeka API'leri ile Türkçeye çeviren ve orijinal dosyalara dokunmadan yama paketi
(_P.pak) üreten çapraz platform bir C# masaüstü uygulaması geliştireceğiz.

ÖNEMLI NOT: Sadece Unreal Engine değil, .pak formatını kullanan her oyunla
çalışacak şekilde genel bir mimari kur.

================================================================================
TEKNOLOJİ YIĞINI
================================================================================

KATMAN 1 — LocalizePak.Core
================================================================================

Tüm katmanların bağımlı olduğu domain modelleri ve soyut arayüzler.

OLUŞTURULACAK DOSYALAR:

--- Models/PakArchive.cs ---
.pak dosyasını temsil eden domain modeli.
Properties: FilePath (string), Version (int), IsEncrypted (bool),
            MountPoint (string), Entries (IReadOnlyList<PakEntry>)

--- Models/PakEntry.cs ---
Arşiv içindeki tek dosya girdisi.
Properties: Path (string), Offset (long), Size (long),
            CompressedSize (long), CompressionMethod (CompressionMethod),
            IsEncrypted (bool), Hash (byte[])

--- Models/LocresFile.cs ---
.locres dosyası domain modeli.
Properties: Version (LocresVersion), Namespaces (List<LocresNamespace>),
            SourceFilePath (string)

--- Models/LocresNamespace.cs ---
Properties: Name (string), Entries (List<LocalizationEntry>)

--- Models/LocalizationEntry.cs ---
Tek çeviri birimi.
Properties: Key (string), KeyHash (uint), SourceText (string),
            TranslatedText (string), Status (TranslationStatus),
            HasVariableError (bool), Notes (string?)

--- Models/AppSettings.cs ---
Kullanıcı tercihleri ve API anahtarları.
Properties: GeminiApiKey (string), OpenAiApiKey (string),
            DeepSeekApiKey (string), SelectedProvider (string),
            MaxConcurrency (int), BatchSize (int),
            UserDirective (string), GlossaryEntries (List<GlossaryEntry>)

--- Models/GlossaryEntry.cs ---
Properties: Original (string), Translation (string?), DoNotTranslate (bool)

--- Models/TranslationContext.cs ---
Properties: UserDirective (string), Glossary (IReadOnlyList<GlossaryEntry>),
            TargetLanguage (string)  // "tr" varsayılan

--- Enums/TranslationStatus.cs ---
Enum değerleri: Pending, Translating, Done, Error, Skipped, ManuallyEdited

--- Enums/CompressionMethod.cs ---
Enum değerleri: None, Zlib, Gzip, LZ4, Zstd, Oodle

--- Enums/LocresVersion.cs ---
Enum değerleri: V1 = 1, V2 = 2, V3 = 3

--- Interfaces/ITranslationProvider.cs ---
interface ITranslationProvider {
    string Name { get; }
    Task<IReadOnlyList<string>> TranslateBatchAsync(
        IReadOnlyList<string> maskedTexts,
        TranslationContext context,
        CancellationToken ct = default);
}

--- Interfaces/IPakReader.cs ---
interface IPakReader {
    Task<PakArchive> OpenAsync(string path, string? aesKey, CancellationToken ct);
    Task<Stream> ExtractFileAsync(PakArchive archive, PakEntry entry, CancellationToken ct);
}

--- Interfaces/IPakWriter.cs ---
interface IPakWriter {
    Task WriteAsync(string outputPath, string mountPoint,
                    IReadOnlyList<(string virtualPath, byte[] data)> files,
                    CancellationToken ct);
}

--- Interfaces/ILocresSerializer.cs ---
interface ILocresSerializer {
    Task<LocresFile> DeserializeAsync(Stream stream, CancellationToken ct);
    Task<byte[]> SerializeAsync(LocresFile locres, CancellationToken ct);
}

KATMAN 2 — LocalizePak.IO
================================================================================

Fiziksel dosya okuma/yazma. Bağımlılık: LocalizePak.Core

OLUŞTURULACAK DOSYALAR:

--- PakService.cs ---
IPakReader ve IPakWriter'ı uygular.

OpenAsync metodu:
1. Dosyanın son 221 byte'ını oku (Footer)
2. Magic number doğrula (0x5A6F12E1)
3. Sürümü tespit et
4. Index offset ve boyutunu oku
5. Şifrelenmiş ise AES-256-CBC ile deşifrele (AesDecryptionHelper kullan)
6. Index'i ayrıştır: mount point + entry dizisi
7. PakArchive nesnesi döndür

ExtractFileAsync metodu:
1. Entry'nin offset'ine git
2. Boyutu oku
3. Gerekiyorsa deşifrele (AES)
4. Gerekiyorsa sıkıştırmayı aç (CompressionMethod'a göre)
5. MemoryStream olarak döndür

WriteAsync metodu:
1. Her dosyayı Zlib ile sıkıştır
2. Entry metadata'sını hesapla
3. Index tablosunu yaz
4. Footer'ı yaz (Magic + Version + IndexOffset + IndexSize + SHA1)

--- LocresService.cs ---
ILocresSerializer'ı uygular.

DeserializeAsync metodu:
1. BinaryReader ile magic GUID oku ve doğrula
2. Sürümü tespit et (Version byte)
3. v2/v3 ise isim dizisini oku
4. Namespace sayısını oku
5. Her namespace için:
   a. Namespace string oku
   b. Giriş sayısını oku
   c. Her giriş için: Key, KeyHash, SourceText oku
6. LocresFile nesnesi döndür

SerializeAsync metodu:
1. Magic GUID yaz
2. Sürüm byte yaz
3. v2/v3 ise güncellenmiş isim dizisini yaz
4. Namespace'leri sırasıyla yaz
5. Her giriş için: Key, KeyHash (değişmez!), TranslatedText yaz
6. byte[] olarak döndür

--- FileFormatDetector.cs ---
İlk byte'ları okuyarak dosya formatını tespit eder.
.pak: Magic 0x5A6F12E1
.locres: GUID magic

--- AesDecryptionHelper.cs ---
static class. InMemory AES-256-CBC şifre çözme.
ValidateKey(string hexKey) → bool
Decrypt(byte[] encrypted, byte[] key, byte[] iv) → byte[]

--- OodleHelper.cs ---
Oodle sıkıştırma için P/Invoke köprüsü.
[DllImport("oo2core_9_win64.dll")] ...
TryDecompress(byte[] compressed, long decompressedSize) → byte[]?
Windows'ta oo2core_9_win64.dll'i arar; bulamazsa null döner.

KATMAN 3 — LocalizePak.Translation
================================================================================

Bağımlılık: LocalizePak.Core

OLUŞTURULACAK DOSYALAR:

--- MaskingEngine.cs ---
Değişkenleri ve özel isimleri maskeler/geri yükler.

Mask(string text, IReadOnlyList<GlossaryEntry> glossary) → (maskedText, MaskMap)
Restore(string maskedText, MaskMap map) → string

Maskeleme sırası:
1. Glossary özel isimleri → [NAME_0], [NAME_1], ...
2. Named değişkenler ({PlayerName}) → [VAR_0], ...
3. Pozisyonel değişkenler ({0}, {1}) → [POS_0], ...
4. Printf formatları (%s, %d) → [FMT_0], ...
5. Escape dizileri (\n, \t) → [ESC_0], ...
6. Rich text / HTML etiketleri → [TAG_0]...[/TAG_0], ...

--- GlossaryManager.cs ---
Sözlük yönetimi.
AutoDetect(IReadOnlyList<string> texts) → IReadOnlyList<GlossaryEntry>
(Büyük harfle başlayan tekrarlayan kelimeler = özel isim adayı)

--- TranslationValidator.cs ---
Çeviri sonrası doğrulama.
Validate(string source, string translated) → ValidationResult
- Maske etiketleri kayıp kontrolü
- Etiket sayısı eşleşme kontrolü
- Boş çeviri kontrolü

--- GeminiTranslationProvider.cs ---
ITranslationProvider uygular. Google Gemini Flash API.

Endpoint: https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent
Model: gemini-2.5-flash (varsayılan)
Context Caching: cachedContent API ile sistem talimatı önbelleğe alınır.

Sistem talimatı şablonu:
  "Sen profesyonel bir oyun yerelleştirme uzmanısın.
   [VAR_X], [NAME_X], [POS_X], [FMT_X], [ESC_X], [TAG_X]...[/TAG_X]
   etiketlerini HİÇBİR ZAMAN çevirme.
   Üslup direktifi: {UserDirective}
   Çevrilmeyecek özel isimler: {GlossaryJson}"

Yanıt formatı: JSON array (sıra korunmalı)

--- OpenAiTranslationProvider.cs ---
ITranslationProvider uygular. OpenAI Chat Completions API.
Endpoint: https://api.openai.com/v1/chat/completions
Model: gpt-4o-mini (varsayılan)

--- DeepSeekTranslationProvider.cs ---
ITranslationProvider uygular. DeepSeek API.
OpenAI uyumlu endpoint: https://api.deepseek.com/v1/chat/completions
Model: deepseek-chat (varsayılan)

--- BatchTranslationOrchestrator.cs ---
Toplu çeviri yönetimi.

TranslateAllAsync(LocresFile locres, ITranslationProvider provider,
                  TranslationContext context, IProgress<TranslationProgress>,
                  CancellationToken ct)

İşlem akışı:
1. Tüm LocalizationEntry'leri düzleştir (flatten)
2. BatchSize'a (varsayılan 50) göre gruplara böl
3. SemaphoreSlim(MaxConcurrency) ile eşzamanlı istek gönder
4. Her batch için:
   a. MaskingEngine.Mask() ile maskele
   b. Provider.TranslateBatchAsync() ile çevir
   c. MaskingEngine.Restore() ile maskeleri geri yükle
   d. TranslationValidator.Validate() ile doğrula
   e. Entry.TranslatedText ve Entry.Status güncelle
5. Progress raporla
6. Rate-limit (429) → Polly ExponentialBackoff

KATMAN 4 — LocalizePak.UI (Avalonia)
================================================================================

Bağımlılık: Tüm katmanlar. MVVM deseni.

OLUŞTURULACAK DOSYALAR:

--- App.axaml + App.axaml.cs ---
DI container kur. Fluent tema + koyu mod.

--- MainWindow.axaml ---
Düzen:
┌─────────────────────────────────────────────────────────┐
│  Menü Çubuğu: Dosya | Ayarlar | Yardım                │
├────────────────┬────────────────────────────────────────┤
│                │  [Üst Araç Çubuğu]                    │
│  Sol Panel     │  Kaynak | Türkçe | Durum | Namespace  │
│  ─────────     │  ─────────────────────────────────     │
│  Dosya Ağacı  │  Sanallaştırılmış DataGrid             │
│  (.locres      │  (100K+ satır performans)              │
│   dosyaları)   │                                        │
│                │  [Alt Panel]                           │
│  [Dosya Seç]   │  Direktif Giriş Kutusu                │
│  [AES Anahtarı]│  [Çeviriyi Başlat] [Durdur]           │
│                │  ProgressBar + Durum Etiketi          │
└────────────────┴────────────────────────────────────────┘
Tema: Koyu (Dark), vurgu rengi mavi/indigo

--- MainViewModel.cs ---
ObservableObject'ten türer. IAsyncRelayCommand'lar:
- OpenPakCommand: Dosya seçici → PakService.OpenAsync
- ExtractLocresCommand: Seçilen .locres'i aç → LocresService.DeserializeAsync
- StartTranslationCommand: BatchTranslationOrchestrator başlat
- StopTranslationCommand: CancellationToken iptal
- ExportPatchCommand: PakService.WriteAsync ile _P.pak üret
- SaveSettingsCommand: AppSettings kaydet

Properties:
- PakEntries: ObservableCollection<PakEntryViewModel>
- LocalizationEntries: ObservableCollection<LocalizationEntryViewModel>
- SelectedProvider: string
- TranslationProgress: double (0.0–1.0)
- StatusMessage: string
- IsTranslating: bool
- UserDirective: string

--- TranslationEditorView.axaml ---
DataGrid bağlantısı MainViewModel.LocalizationEntries'e.
Sütunlar: Namespace, Key, Kaynak Metin, Türkçe Çeviri (düzenlenebilir), Durum
Filtreleme: Sadece Hatalı / Sadece Bekleyen
Hata durumu: Kırmızı arka plan

--- SettingsView.axaml ---
API anahtarları için PasswordBox
Model seçimi için ComboBox
BatchSize ve MaxConcurrency için NumericUpDown

--- GlossaryView.axaml ---
DataGrid: Orijinal | Çeviri | Çevirme
Otomatik tespit butonu
CSV dışa/içe aktar
